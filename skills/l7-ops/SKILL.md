# Operate

Establish or update the operating cadence. Do not start a new feature here; create the evidence that `/l7-change` will use.

## Work

1. Define or refresh SLIs/SLOs and alerts
2. Summarize incidents and open bugs
3. Collect product signals: activation, retention, support themes, cost
4. Triage P0-P3
5. Propose a scored Version 2 backlog
6. Write `docs/artifacts/post-launch-operations-report.md`

If the user already has a specific feature in mind, recommend `/l7-change` after this report exists or is updated.

Then recommend `/l7-next`.
