# Level 7 Headless

Prefer local MCP `l7_v1_headless`; use the plugin-relative `l7 headless`
commands only when MCP is unavailable.

Before planning, require a finalized `concept.md` or feature-wave manifest with
measurable acceptance criteria, exact allowed paths, exact verification argv,
a target local branch, and a Tier 2 ceiling. Planning must bind the objective
digest and exact base commit.

Show this warning before start: approval begins an autonomous, durable
multi-session loop across every approved Tier 1/2 wave and permitted local
merge. It may wait for natural quota reset and resume after restart. It stops
for scope expansion, protected paths, Tier 3 work, secrets, destructive or
external effects, divergent targets, three identical no-progress failures, or
missing independent review. It always stops before remote push, release, or
deployment.

Start only after the user confirms the exact manifest digest with their name
and role. Never purchase credits or consume reset credits. Use status, resume,
or cancel against the durable checkpoint; never replace this lifecycle with
clipboard automation, `/new`, or an arbitrary session cap.
