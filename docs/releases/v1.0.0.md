# Level 7 Dev Loop v1.0.0

Level 7 v1.0.0 is the first stable, bundled multi-host orchestration release.
It packages the same 16 skills, native `l7` engine, local MCP bridge, and Apple
Natural Language embedding helper for Codex and Claude Code.

## Installable assets

Use only these four attached release assets:

- `level7-dev-loop-1.0.0-codex.zip`
- `level7-dev-loop-1.0.0-claude.zip`
- `SHA256SUMS`
- `RELEASE-MANIFEST.json`

GitHub-generated source ZIPs and tarballs are not installable v1 packages. The
manifest binds the exact merged commit and tree, clean unsigned input digests,
accepted Apple notarization submissions, final archive digests, checksums, and
this release-note digest. GitHub artifact attestations cover all four attached
assets.

Follow the [v1.0.0 install and verification instructions](https://github.com/addressanup/level7-dev-loop#install-v100)
before registering either extracted local marketplace.

## What ships

- Default-off onboarding, provider discovery, explainable routing, and effort
  escalation across authenticated Codex, Claude Code, and explicitly
  configured compatible gateways.
- Private Git-bound codebase memory, read-only-first Cyber audits, bounded
  remediation, and durable multi-wave Headless execution with recovery and
  failover.
- Signed macOS arm64 and amd64 executables, host-specific local catalogs,
  closed package inventories, checksums, SPDX SBOMs, and release-blocked input
  provenance that cannot grant publication authority.
- Hard stops before push, protected merge, release, installation, deployment,
  destructive actions, unsupported scope expansion, or missing authority.

## Compatibility and safety boundary

v1.0.0 supports macOS 13+ on Apple Silicon and Intel. Publication requires the
unchanged baseline, Go shadow, macOS arm64, macOS amd64, paired benchmark, and
trusted policy checks to pass for the exact pull-request head. It also requires
exact-archive Codex and Claude marketplace, installation, discovery, named
skill, provider execution, uninstall, marketplace removal, and residue trials.
The run-bound trial record on the merged release pull request names the observed
host versions, architecture, provider/model, archive digests, transcript
digests, and cleanup results.

Those observations do not transfer to another archive, host version, operating
system, architecture, model, provider configuration, or release. Level 7 is
not a sandbox: host permissions and credentials remain the enforcement
boundary. Optional gateway secrets stay user-managed and are referenced, never
stored in Level 7 policy.

## Update, uninstall, and rollback

Remove the installed v1 plugin and `level7-engineering-v1` marketplace before
changing its retained extraction root. Verify a replacement release before
installation and never overwrite an existing root. Uninstall does not remove
repositories, credentials, provider configuration, or unrelated host state;
inspect private `.git/l7` state separately.

The unchanged [v0.1.1 release](https://github.com/addressanup/level7-dev-loop/releases/tag/v0.1.1)
remains available as the skills-only rollback. Remove v1 first, then register
and install the tag-pinned `level7-engineering` marketplace as documented in
the README.
